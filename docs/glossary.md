# Glossary

| Term | Simple meaning | Arabic |
|---|---|---|
| Requirement | Something the system must do or be | متطلب |
| Functional requirement (FR) | An action the system performs | متطلب وظيفي |
| Non-functional requirement (NFR) | How well the system works, with a number | متطلب غير وظيفي |
| Constraint | A fixed rule you cannot change | قيد |
| Assumption | Something you believe but have not confirmed | افتراض |
| Scope | What is included in the project, and what is not | النطاق |
| Stakeholder | A person or group who cares about the system | صاحب مصلحة |
| Availability | The percentage of time the system works | التوافر |
| Latency | How long a response takes | زمن الاستجابة |
| Scalability | Ability to handle more users or data | قابلية التوسع |
| SLA | The availability a provider promises | اتفاقية مستوى الخدمة |
| RTO | Maximum time the system may be down after a failure | الوقت المستهدف للاستعادة |
| RPO | Maximum data that may be lost after a failure | نقطة الاستعادة المستهدفة |
| Region | A geographic area with Azure datacenters | منطقة |
| Availability zone | A separate datacenter inside a region | منطقة توافر |
| Resource group | A folder that groups Azure resources for management | مجموعة الموارد |
| Virtual network (VNet) | A private network in Azure | شبكة افتراضية |
| Subnet | A smaller part of a VNet | شبكة فرعية |
| Private endpoint | A private IP address that connects to a PaaS service | نقطة نهاية خاصة |
| Managed identity | An identity Azure gives a service, so no passwords are needed | هوية مُدارة |
| Data residency | Where data is physically stored | توطين البيانات |
| Encryption | Protecting data so only allowed parties can read it | التشفير |
| Synchronous | The caller waits for the answer | متزامن |
| Asynchronous | The caller does not wait; the work happens later | غير متزامن |
| Trade-off | Gaining one thing by giving up another | مفاضلة |
| Mitigation | An action that reduces a risk | تخفيف المخاطر |
